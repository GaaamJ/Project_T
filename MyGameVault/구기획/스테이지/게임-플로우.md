# 스테이지 — 게임 플로우

## 컨텍스트

플레이어와 자매는 던전 입구에서 보스에게 추격당한다. 도망치기 위해 노드를 연결하며 안전 지대로 향한다.

## 라운드 흐름

1. 자매가 묶는 구간에서 Observe → Bind 수행. 플레이어는 자매 보호.
2. 플레이어가 연결 구간에서 정답 노드를 연결. 자매가 따라다님.
3. 장애물(점프맵 + 장판)을 처리하며 다음 아레나로 이동.
4. 총 4회 반복.

## 클리어 / 실패

- 잘못된 노드 연결 → 즉시 Wiped (스테이지 재시작).
- 제한 시간 초과 → (설계 미확정, 백로그).
- 4라운드 클리어 → 안전 지대 도달 (클리어 루프 미구현, 로드맵 단계 12).

## 자매 AI (예정)

- 묶는 구간: 자매가 지정 위치에서 대기.
- 연결 구간: 자매가 플레이어를 따라다님.
- 로드맵 단계 13 참조.

## 백로그

- Fail 시 스테이지 전체 재시작 로직 (현재 Debug.Log만 출력).
- 클리어 시 다음 구간 진행 로직.
- Observe/Bind 호출 주체 — 현재 StarlightEncounterController가 자동 시퀀싱, 추후 자매 AI·연출 시스템과 연결 설계 필요.
