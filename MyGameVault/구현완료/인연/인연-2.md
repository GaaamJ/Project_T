# 인연 #2

## 0. 개요

게임 플레이 메커니즘 중 하나인, 플레이어와 주인공이 서로 정보를 교환하는 시스템이다. 정보를 교환해 플레이어는 기믹 해결의 단서를 얻거나, 주인공에게 올바른 정보를 전달하게 된다.

1. 플레이어는 주인공과 정보를 교환하며 합을 맞춰 나가는 느낌을 받는다.
2. 정보를 교환하고, 기믹을 해결하며 플레이어는 주인공들에게 애착을 갖게 한다.

## 1. 조작

- 플레이어는 선택지를 고를 수 있다.
  - 선택지는 최대 4개
  - 숫자 키 1 ~ 4를 눌러 선택

## 2. 2차 프로토타이핑

**< 체크리스트 >**
- [x] 주인공과 소통하는 느낌이 나는지 확인한다.

**< 구현 >**
- 대화 시스템을 확장한다.
- 선택지 UI를 간단하게 만든다.
- 최신 Input System을 사용한다.

**< 게임 진행 >**
- 플레이어가 동생에게서 정보를 얻는다. 플레이어가 동생에게 정보를 준다.

**< 스코프 외 >**
- 소통하는 느낌만 검증하므로, 기믹 및 압박 요소(자원, 시간 제한, 복잡한 기믹 등)는 구현하지 않는다.

## 3. 백로그

- 플레이 흐름을 끊지 않기 위해, 이동하며 대화할 수 있는 경우가 있다.
  - 좌중단에 디스코드처럼 캐릭터 portrait를 두고,
- 대사의 일부 글자에 색상, 크기, 애니메이션, SFX를 적용해 캐릭터들의 감정을 전달한다.
  - 추후 Text Animator로 해당 특수 효과를 적용한다. (Yarn Spinner와 연동 확인됨)
- 대사들이 트리거되는 방법, 시점을 정한다.
- 대사들의 우선순위를 정하는 방법을 생각한다.

## 구현 참고

- `StandingCGChanger.cs`, `AlphaValueController.cs`: 캐릭터 스프라이트 비주얼 제어 (감정 표현용).
- `NumberKeyOptionSelector.cs`: 선택지 입력 처리. 숫자 1~4로 하이라이트 이동, Space로 확정 제출.
- `AskHelpTrigger.cs`: 플레이어가 주인공에게 말 걸기 트리거. `NodeManager.GiveSymbolHint()`와 연동 — 확인 필요.
- 대사 관리는 Yarn Spinner(Yarn.Unity) 기반. `NodeManager.cs`에서 `DialogueRunner`를 직접 참조해 `StartDialogue()` 호출.
