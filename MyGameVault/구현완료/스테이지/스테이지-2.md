# 스테이지 #2

## 0. 개요

별빛 #6에서 변경된 기믹에 따라, 스테이지가 변경된다.
플레이어와 자매는 던전 입구에서, 추격해 오는 보스에게 도망치기 위해 노드를 연결하고 안전 지대로 향해야 한다.

## 1. 레퍼런스

- 데스티니 2 섀도우킵 레이드, 구원의 정원, 축성의 정신 회피 (1넴)

## 2. 맵 구조

맵 구조가 선형적이고 길게 변경되었다.
- 테스트로, 3개의 노드 중 하나를 연결해야 한다. 총 4번 진행한다.
- 노드와 노드의 간격, 이동 속도, 시간 제한은 플레이 테스트 중 결정한다.
- 장애물은 점프맵 + 장판으로 구현한다.
  - 점프맵의 느낌은 갭 이동, 통로 이동으로 대체한다.
- 자매가 관측하고 묶는 구간과, 플레이어가 노드를 연결하는 구간을 분리한다.
  - 묶는 구간에서 자매는 대기하며 기믹을 수행하고, 연결하는 구간에서 자매는 플레이어를 따라다닌다.
- <천장> 구조물
  - 씬 전환 없이 단일 카메라 내에서 천장 아래로 내려가면 지붕이 투명해지고 내부가 드러난다.
  - 3D 게임의 y축을 표현하기 위함이다.
- 아슬아슬한 제한 시간 안에, 올바른 노드의 위치를 찾는 과정에서 리트하며 노드의 위치를 발견하게 하고 싶음.
  - 아우터 와일즈, 데스티니의 던전/레이드 초행 느낌

## 3. 기타 사항

- 탑다운 뷰

## 4. 구현 순서

| 단계 | 내용 | 검증 기준 |
|---|---|---|
| 1 | 올바른 노드 지정 — 3개 중 1개가 정답인 시스템 | 정답 노드 작동 확인 |
| 2 | 동생 + 언니 기믹 코어 — 관찰→묶기→제한시간 | 타이머 생성/만료 작동 |
| 3 | 시각적 피드백 — 노드 흐릿함→동생 반응→선명해짐 | 눈으로 흐름 확인 |
| 4 | 맵 재구성 — 선형 4구간 (장애물 없이 기본만) | 공간 이동 확인 |
| 5 | 자매 AI — 대기(묶는 구간) / 따라다니기(연결 구간) | 자매 이동 확인 |
| 6 | 보스 추격 AI | 추격 압박 확인 |
| 7 | 장판 + 대시/패리 보호 | 보호 기믹 작동 |
| 8 | 천장 구조물 투명화 | 시각 확인 |
| 9 | 안전 지대 + 클리어 조건 | 엔드 조건 작동 |
