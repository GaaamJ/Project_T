# 이벤트 관리

## 역할

게임 내 이야기 단위인 이벤트의 실행 조건과 완료 상태를 관리한다.

## 이벤트란

대사, 컷씬, 캐릭터 연출로 이루어진 이야기 단위다.
각 이벤트는 고유 ID, Yarn 노드, 실행 조건을 가진다.

## 동작

### 실행 흐름

씬이 시작되면 등록된 이벤트의 실행 조건을 확인하고, 조건이 충족되면 Yarn 노드를 실행한다.
Yarn이 끝나면 해당 이벤트를 완료로 기록한다.
실행이 거부되거나 중단된 경우는 완료로 기록하지 않는다.

### 실행 조건

이벤트마다 아래 조건을 설정할 수 있다. 모두 통과해야 실행된다.

| 조건 | 설명 |
| --- | --- |
| 반복 정책 | Once: 완료된 이벤트는 다시 실행하지 않는다 |
| 선행 이벤트 | 지정한 이벤트가 완료되어야 실행된다. All(전부) 또는 Any(하나 이상) 중 선택한다 |
| 중복 실행 | 이미 실행 중인 이벤트가 있으면 새 요청은 거부된다 |

선행 이벤트를 지정하지 않으면 판정 방식과 관계없이 통과한다.

### 완료 기록

- 완료된 이벤트 ID는 저장 파일에 기록된다.
- 게임을 다시 시작해도 완료 기록이 유지된다.

## 이벤트 추가 방법

1. Yarn 스크립트에 노드를 작성한다.
2. 이벤트 정의 에셋을 생성하고 ID, Yarn 노드, 반복 정책, 선행 이벤트를 설정한다.
3. 이벤트가 발생할 씬에 등록한다.

## 규칙

- 이벤트 ID는 중복될 수 없다.
- 한 번 사용한 ID는 변경하지 않는다. 저장 파일의 완료 기록 키로 쓰이기 때문이다.
