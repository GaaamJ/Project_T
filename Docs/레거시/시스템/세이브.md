# 세이브

## 역할

게임 진행 상태를 저장하고 불러온다.

## 저장 항목

| 항목 | 설명 |
| --- | --- |
| 프롤로그 완료 여부 | 타이틀에서 다음 씬 분기에 사용한다 |
| 플레이어 이름 | 미입력 시 비어 있다 |
| 완료된 이벤트 목록 | 이벤트 관리 시스템과 연동된다 |

## 동작

- 게임 시작 시 저장 파일을 불러온다. 파일이 없으면 기본값으로 시작한다.
- 이벤트가 완료되면 자동으로 저장된다.

## 규칙

- 게임 진행 상태만 저장한다. 볼륨 등 설정값은 별도로 관리한다.
- 이벤트 완료 상태는 이벤트 관리 시스템만 변경한다. [[이벤트 관리]] 참고.
