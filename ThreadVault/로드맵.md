# 로드맵

프로토타입 완성을 위한 작업 순서. 각 단계가 끝나야 다음 단계가 의미 있어지는 순서로 정렬.

1. **실패 조건 구현** (Issue #28) — 체력 / 맵 패턴 / 패리
2. **대화 UI 탭** — 플레이어가 먼저 말 거는 UI 탭 + 선택지 (Issue #18 스코프 외)
3. **세계관 + 장소 확정 → 우미아 캐릭터성 정의**
4. **프롭 제작 + Interact 대사** — 세계관 확정 후 진행
5. **대사 전체 작성** — 임시 대사 교체
6. **맵 꾸미기 + Lighting**
7. **아트 에셋 교체 + 애니메이션 적용**
8. **폴리싱** — 플레이하며 조정
