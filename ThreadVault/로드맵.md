# 로드맵

프로토타입 완성을 위한 작업 순서. 각 단계가 끝나야 다음 단계가 의미 있어지는 순서로 정렬.

1. **실패 조건 구현** (Issue #28) — 체력 / 맵 패턴 / 패리
   - 실패 조건이 게임에 긴장감을 주기 때문에 먼저 구현한다.
2. **대화 UI 탭** — 플레이어가 먼저 말 거는 UI 탭 (Issue #18 스코프 외). 선택지는 현재 보류.
3. **세계관 + 장소 확정 → 우미아 캐릭터성 정의**
   - 세계관·장소를 정하고 우미아의 캐릭터성을 정의한 뒤 프롭과 대사를 만드는 순서가 자연스럽다고 생각했다.
4. **프롭 제작 + Interact 대사** — 세계관 확정 후 진행
5. **대사 전체 작성** — 임시 대사 교체
6. **맵 꾸미기 + Lighting**
7. **아트 에셋 교체 + 애니메이션 적용**
   - 맵 꾸미기·아트 교체·애니메이션을 뒤쪽에 둔 것도 작업 순서가 자연스럽다고 생각해서다.
8. **폴리싱** — 플레이하며 조정
