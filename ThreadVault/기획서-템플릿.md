# 기능명

## 역할

게임에서 이 기능이 하는 일과 의도.

기능 전체의 목적은 여기에 남긴다. 개별 선택의 이유는 해당 동작이나 규칙 바로 아래에 붙인다.

## 동작

시작부터 종료까지의 흐름.
종료·실패·초기화 시 처리.

내용이 많으면 상황이나 진행 단계별 소제목으로 묶는다. 짧은 문서는 목록만 사용한다.

## 규칙

조건, 수치, 제한, 예외.

내용이 많으면 같은 주제끼리 소제목으로 묶는다.
기존 문서를 정리할 때는 원문의 문장을 최대한 유지하고, 배치와 줄 나눔을 먼저 조정한다.
사용자가 설명한 이유와 불확실성을 유지하고, 답하지 않은 의도는 추측해 채우지 않는다.
