# 실과 운명

실타래를 수집해 실 버프를 얻고, 버프를 소모해 좌표를 묶어 스테이지를 클리어하는 기믹이다.

## 실타래

### 역할

파괴 시 사라지며 타입에 따라 서로 다른 실 버프를 얻을 수 있는 오브젝트이다.
- 종류를 만든 이유: 실(원인)에 따른 결과가 달라질 수 있다는 가능성을 열어 두고 싶었음.

### 동작

- 스테이지 시작(시작 구역 이탈) 시 붉은색 / 푸른색 / 금빛을 각 1개씩 생성한다.
  - 색을 정할 때 운명의 붉은 실, 황금빛 양털로 짠 실 같은 느낌을 생각했다.
- 플레이어의 공격을 받으면 해당 타입의 실 버프를 주고 사라진다.
- 버프가 소모·만료되면 남은 실타래를 없애고 3색을 새 위치에 다시 생성한다.
- 다른 타입의 버프로 교체되면 이전 타입의 실타래만 다시 생성한다.

### 규칙

**생성 위치**
- 지정된 후보 중 빈 위치를 랜덤으로 선택한다. 같은 위치에 중복 생성하지 않는다.
  - 완전 랜덤이면 플레이어가 예측할 수 없고, 고정 위치면 힌트의 가치가 사라지기 때문에 이 방식을 골랐다.
- 가장 최근에 실타래를 습득한 방에서는 스폰되지 않는다. 새 실타래를 다른 방에서 습득하면 제한이 그 방으로 이동한다.
- 방금 수집한 위치는 다음 전체 재배치 1회에서도 제외한다.
  - 두 규칙 모두 힌트의 가치를 높이기 위한 것이다.

**타입 제한**
- 같은 타입의 실타래는 동시에 2개 이상 존재하지 않는다.
- 보유 중인 버프와 같은 타입의 실타래는 생성하지 않는다.
  - 한 가지 원인을 선점했으니 더 이상 관련된 원인이 나오지 않아야 한다고 생각했다.

## 실 버프

### 역할

좌표를 활성화할 수 있는 버프이다. 플레이어가 보유하고 운반한다.

### 동작

**획득과 교체**
- 실타래를 파괴하면 해당 타입의 버프를 얻는다.
- 새 버프를 얻으면 보유 타입을 교체하고 지속시간을 다시 채운다.

**소모와 만료**
- 좌표에 묶으면 소모된다.
  - 원인인 실이 흔들리던 좌표를 관측해 거기에 고정시킨다는 느낌을 생각했다. 코펜하겐 해석에서 가져왔다.
- 남은 시간이 0이 되면 만료된다.
- 소모·만료 시 남은 실타래를 전체 재배치한다. 활성화된 좌표는 유지한다.

### 규칙

- 한 번에 한 가지 버프만 보유한다.
  - 여러 가지 실을 들면 실이 엉켜 문제가 생긴다는 것을 보여주고 싶었다.
- 붉은 / 푸른 / 금빛 타입 모두 같은 지속시간을 사용한다.
- SandBox의 지속시간은 19.3초다.
  - 가장 먼 실타래 스폰 후보에서 가장 먼 좌표까지 이동하는 시간에 5초의 여유를 더해 정했다.
- 다른 타입으로 교체하면 이전 타입의 실타래를 다시 생성한다.

## 좌표

### 역할

실 버프를 묶는 지점. 활성 / 비활성 상태로 나뉜다.

### 동작

- 실 버프가 있을 때 상호작용을 완료하면 버프를 소모해 좌표를 묶는다.
- 묶인 좌표는 활성 상태가 되고, 소모한 버프의 타입을 가진다.
- 이미 활성화된 좌표에도 다시 묶을 수 있다. 묶을 때마다 버프를 소모하고 타입을 갱신한다.
  - 결과가 얼마든지 바뀔 수 있음을 의미하며, 플레이상으로도 자연스럽다고 생각했다.
- 묶인 타입에 맞춰 모습이 바뀐다.

### 규칙

- 실 버프가 없으면 묶을 수 없다.
- 실타래 재배치나 버프 만료로 활성 상태가 해제되지 않는다.
- 6개 전부 활성화되면 스테이지 클리어가 발생한다.

## 스테이지 흐름

- **대기**: 씬 시작 직후. 플레이어가 시작 구역에 있으며 실타래는 스폰되지 않는다.
- **진행**: 시작 구역을 벗어난 순간 3색 실타래가 스폰되며 시작된다.
- **클리어**: 좌표 6개 전부 활성화 시 발생한다.
- **리트라이**: 실패 조건 발생 시 버프·좌표·실타래가 전부 초기화되고 플레이어가 시작 구역 중앙으로 워프된다.

## 조작

**공격 (실타래 파괴)**
- 마우스 커서 방향으로 레이캐스트를 쏴 범위 안의 실타래를 타격한다.

**상호작용 (좌표 묶기)**
- 좌표 감지 범위 안에서 상호작용 키를 홀드하면 좌표에 버프를 묶는다.
- 범위를 벗어나거나 홀드를 중단하면 취소된다.

## UI

**버프 패널**
- 현재 보유한 실 타입과 잔여 초를 표시한다.
- 버프가 없으면 패널을 숨긴다.

**홀드 게이지**
- 좌표 감지 범위 안에서 홀드 시 진행 게이지를 표시한다.
- 홀드 완료 또는 취소 시 게이지를 숨긴다.
- 게이지는 좌표 오브젝트 각각에 부착된다.
