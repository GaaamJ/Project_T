# 협력 구조

## 역할

플레이어와 우미아는 서로에게 꼭 필요한 존재여야 한다.

실의 확보·운반·반납은 둘이 함께 진행하는 과정이다. 우미아의 안내는 우미아의 역할이 중요하다는 것을 나타내고, 서로 협력한다는 장치다.

실타래 파괴 → 실 버프 획득 → 중앙 반납을 배우는 튜토리얼.

## 동작

- 플레이어와 우미아는 함께 방을 탐색하고 실을 확보·운반·반납한다. 이동·공격·반납 조작은 플레이어가 수행한다.
- 우미아는 플레이어와 동행하며 실타래 생성 시 방문 기록에 따라 대사를 재생한다.
- 현재 방 안내는 임시 대사로 방 위치를 직접 전달한다.
  - 기능 확인을 위해 넣은 임시 대사다.
- 구체적인 안내 분기는 [[대화 시스템 트리거]], 이동은 [[우미아]]를 따른다.

## 규칙

- 우미아는 실타래를 직접 수집하거나 좌표에 반납하지 않는다.
  - 직접 수집·반납하는 방식을 시도했지만 너무 어색하게 느껴졌다.
- 실타래 재배치 이후 안내 판정은 새로 생성된 실타래의 방을 기준으로 한다.
