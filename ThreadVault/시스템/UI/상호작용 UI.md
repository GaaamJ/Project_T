# 상호작용 UI

## 역할

플레이어에게 상호작용 진행 상태를 전달한다.

## 동작

- 감지한 좌표에서 F를 누르기 시작하면 해당 좌표 위에 게이지가 차오른다.
  - 게이지가 차오르는 것으로 무언가 하고 있다는 것을 보여주고 싶었다.
- 입력 취소·상호작용 완료·게이지 시간 완료 시 숨긴다.
  - 입력을 취소하거나 상호작용이 끝나면 게이지를 숨기는 것이 자연스럽다고 생각했다.

## 규칙

- 상호작용 게이지는 좌표 위에 표시한다. 실제 버프 소모와 좌표 활성화는 [[좌표]] 규칙을 따른다.
  - 해당 대상 위에 표시하는 것이 그 대상에 무언가 하고 있다는 느낌을 더 주기 때문이다.
