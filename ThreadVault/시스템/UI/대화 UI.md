# 대화 UI

## 역할

플레이어가 우미아와 대화하며 관계를 구축하는 데 집중할 수 있도록 필요한 정보를 간결하게 표시한다.

## 동작

- 대화 시작 시 대화 화면을 표시하고 종료 시 숨긴다.
  - 대화할 때만 화면을 표시하는 것이 자연스럽다고 생각했다.
- 대사에서 캐릭터 이미지와 투명도를 변경할 수 있다.
  - 말하는 사람과 나레이션을 구분하기 위한 것이다.
- 백틱 키로 도움말 대화를 요청할 수 있다. 이미 대화 중이면 요청을 대기열에 추가하고, 기존 대사가 끝난 뒤 순서대로 재생한다. 자세한 조건은 [[대화-시스템-트리거]]를 따른다.

## 규칙

- 대화 선택지 기능은 현재 보류 상태다.
