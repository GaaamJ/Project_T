# 버프 UI

## 역할

플레이어에게 버프 상태를 전달한다.

## 동작

- 실 버프를 보유하는 동안 화면 좌중단에 버프 이름과 남은 시간을 표시한다.
  - 좌중단 배치는 임시로 정한 표시 위치다.
- 이름은 붉은 실 / 푸른 실 / 금빛 실이다.
- 남은 시간은 소수점을 버린 정수로 표시한다.
  - 소수점이 있으면 난잡하게 느껴져서 생략했다.
- 버프가 소모되거나 만료되면 패널을 숨긴다. 재획득·교체하면 내용을 갱신한다.
  - 버프가 없을 때 패널을 숨기는 것이 자연스럽다고 생각했다.

## 규칙

- 버프 글꼴은 Galmuri11을 사용한다.
