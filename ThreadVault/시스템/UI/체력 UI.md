# 체력 UI

## 역할

플레이어와 우미아의 공유 체력 및 집중 회복 진행을 알려 준다. 필요한 순간에만 표시해 평상시 화면의 정보를 줄인다.

## 동작

### 형태와 위치

- 외곽 테두리 안에 작은 막대가 들어가는 형태다.
- 체력 판정은 0·1·2지만, UI에는 칸 구분선을 넣지 않고 내부 막대의 길이로 표현한다.
- 화면에 고정한다. 화면 중앙 상단 배치를 임시안으로 둔다.

### 체력별 표시

| 실제 체력 | 내부 막대 길이 | 기본 색상 |
| ----- | -------- | ----- |
| 2     | 100%     | 흰색    |
| 1     | 50%      | 빨간색   |
| 0     | 아주 짧게 남김 | 빨간색   |

- 최대 체력에서는 기본적으로 UI를 숨긴다.
- 우미아가 피격되어 체력이 감소하면 즉시 표시한다. 체력 1인 동안에는 계속 표시한다.
- 체력 0에서도 막대를 조금 남겨 스토리상 죽은 것이 아님을 표현한다. 실제 체력은 0이며 스테이지 실패 판정에는 영향을 주지 않는다.
### 집중 회복

- 제자리에서 회복 버튼을 유지하면 집중 회복을 시작한다.
- 집중하는 2초 동안 내부 막대가 50%에서 100%까지 서서히 차오른다.
- 시작 시 빨간색이며, 집중 시작 후 1초가 지나면 흰색으로 바뀐다.
- 실제 체력은 2초 완료 시 1칸 회복한다. 도중의 막대 길이와 흰색 변화는 회복 진행 표현이며, 체력이 미리 회복된다는 뜻은 아니다.

### 집중 취소

- 이동·공격·패링·우미아 피격·회복 버튼 해제 시 집중을 취소한다.
- 취소하면 내부 막대가 실제 체력에 해당하는 길이로 빠르고 부드럽게 줄어든다. 체력 1을 유지한 채 취소하면 50%로 돌아간다.
- 집중 중 흰색으로 바뀌었어도 취소 시 빨간색으로 돌아간다.
- 다시 집중하면 진행 시간을 처음부터 채운다.

### 회복 완료

- 완료 시 내부 막대는 흰색 100%가 된다.
- 별도 대기 시간 없이 완료 직후부터 1.5초에 걸쳐 UI가 페이드아웃한다.
- 사라지는 중 다시 피격되면 즉시 표시하고, 감소한 체력에 맞춰 갱신한다.

## 규칙

- 공유 체력은 최대 2칸이며, 피격 판정은 우미아에게만 있다.
- 모든 공격은 1칸의 피해를 주고, 피격 후 0.5초간 무적이다.
- 회복 방해 구역은 우미아 위치를 기준으로 판정한다. 구역 밖에서는 어디서든 집중 회복할 수 있다.
- 재도전 시 체력은 2칸으로 초기화한다.
- 회복 시간 2초는 플레이 후 조정할 임시 수치다.

## 미정

- 체력 0에서 남길 막대의 최소 길이와 실패·재도전 전환 중 표시 시간.
- 집중 취소 시 막대가 줄어드는 시간과 움직임의 세부 조정.
- UI 크기, 테두리와 내부 여백, 정확한 화면 위치.
- 회복 불가 시 피드백. 흔들림 등을 후보로 두며 아직 확정하지 않는다.
