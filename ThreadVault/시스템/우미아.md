# 우미아

## AI

스테이지 상태에 따라 행동 방식이 달라진다.

- 사람처럼 행동한다. 항상 최선을 선택하지 않는다.
- 맵 지식은 탐색을 통해 발견하며, 리트라이 후에도 유지된다.
- 타겟 위치를 모를 때는 랜덤하게 돌아다닌다.
- 시야 범위 내, 벽에 가려지지 않은 오브젝트만 발견한다.
- Player 태그를 부착한다.

### 스테이지 대기 / 클리어
여타 어드벤처 RPG처럼, 플레이어와 함께 이동한다.

### 스테이지 진행 중
[[실-버프]]를 보유한다. 플레이어와 별도로 이동한다.

**실 버프가 없을 때**
[[실타래]]를 찾아 파괴하고 실 버프를 얻는다.
- 아는 스폰 위치를 직접 방문해야 [[실타래]] 유무를 확인할 수 있다.

**실 버프가 있을 때**
[[좌표]]를 찾아 묶는다.
- 비활성 좌표를 목표로 삼는다.
- 이미 활성화된 좌표는 목표로 삼지 않는다.
- 플레이어가 상호작용 중인 실타래나 좌표는 목표로 삼지 않는다.

## 상태 머신

```
Explore ←→ SeekYarn ←→ SeekCoordinate
```

| 상태                 | 진입 조건                          | 이탈 조건                                                |
| ------------------ | ------------------------------ | ---------------------------------------------------- |
| **Explore**        | 초기 상태 / 아는 스폰을 모두 방문했지만 실타래 없음 | 미방문 스폰 발견 → SeekYarn / 실 버프 + 아는 좌표 → SeekCoordinate |
| **SeekYarn**       | 미방문 스폰포인트가 있음                  | 실타래 수거 → SeekCoordinate / 모든 스폰 방문 실패 → Explore      |
| **SeekCoordinate** | 실 버프 보유 + 아는 비활성 좌표 있음         | 좌표 바인드 완료 → SeekYarn / 실 버프 소진 → SeekYarn            |

## Explore — 탐색 동작

이전 위치의 반대 방향을 **앞(forward)** 으로 정의한다.
갈림길 구조를 인식해 DFS 방식으로 모르는 구역을 우선 탐색한다.

### 탐색 우선순위

1. **외길 (출구 1개)** — 앞으로 계속 직진한다.
2. **갈림길 (출구 2개 이상)** — 미탐색 방향 중 랜덤으로 선택한다. 미탐색 방향이 없으면 탐색된 방향 중 랜덤.
3. **막다른 길** — 온 방향으로 되돌아간다.
4. **갈림길 + 시야 내 실타래** — 실타래 쪽 방향으로 편향 선택한다 (도트곱 임계값 적용).
5. **DFS 심화** — 한 분기 끝까지 탐색한 뒤 갈림길로 돌아와 다음 미탐색 분기로 이동한다.

### 텔레포터 처리

텔레포터는 **시야 범위 내에 있을 때만** 출구로 인식한다.
시야 밖 텔레포터는 갈림길 계산에서 제외된다.

시야 내 텔레포터가 있을 때, "그 너머를 아는지" 여부에 따라 행동이 갈린다.
"그 너머를 안다" = 텔레포터 목적지 주변을 이미 방문한 적 있음.

| 상황 | 행동 |
|------|------|
| 목적지 **알고** + 텔레포터가 유일한 길 | 가거나 되돌아가거나 (랜덤) |
| 목적지 **모르고** + 텔레포터가 유일한 길 | 일단 가 봄 |
| 목적지 **알고** + 다른 길도 있음 | 랜덤 |
| 목적지 **모르고** + 다른 길도 있음 | 텔레포터 우선 탐색 |

### wanderRetryTimeout

모든 아는 스폰을 방문했지만 실타래를 못 찾은 경우, 일정 시간 탐험 후 스폰 재방문을 허용한다.

## 시야

- 시야 반경 내, 벽에 가려지지 않은 오브젝트만 인식한다.
- 벽 판정: Wall 레이어 대상 LinecastAll.
- 시야 범위 안에서 발견한 스폰포인트/좌표 위치는 맵 지식에 저장한다.

---

## 맵 지식

- 발견한 **실타래 스폰포인트** 위치를 기억한다.
- 발견한 **좌표** 위치를 기억한다.
- JSON 파일로 저장되어 리트라이 후에도 유지된다.
- 탐색 범위는 coarse grid(셀 단위)로 관리한다.
