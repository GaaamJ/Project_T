# UI

## 역할
플레이어에게 버프와 상호작용 진행 상태를 전달한다.
플레이어가 우미아와 대화하며 관계를 구축하는 데 집중할 수 있도록 필요한 정보를 간결하게 표시한다.

## 동작
### 버프 표시
- 실 버프를 보유하는 동안 화면 좌중단에 버프 이름과 남은 시간을 표시한다.
- 이름은 붉은 실 / 푸른 실 / 금빛 실이다.
- 남은 시간은 소수점을 버린 정수로 표시한다.
- 버프가 소모되거나 만료되면 패널을 숨긴다. 재획득·교체하면 내용을 갱신한다.

### 상호작용 게이지
- 감지한 좌표에서 F를 누르기 시작하면 해당 좌표 위에 게이지가 차오른다.
- 입력 취소·상호작용 완료·게이지 시간 완료 시 숨긴다.

### 대화
- 대화 시작 시 대화 화면을 표시하고 종료 시 숨긴다.
- 대사에서 캐릭터 이미지와 투명도를 변경할 수 있다.
- 숫자키 1~4로 선택지를 선택하고 스페이스로 제출한다.
- 백틱 키로 도움말 대화를 요청할 수 있다. 이미 대화 중이면 새로 시작하지 않는다.

## 규칙
- 버프 글꼴은 Galmuri11을 사용한다.
- 상호작용 게이지는 좌표 위에 표시한다. 실제 버프 소모와 좌표 활성화는 [[좌표]] 규칙을 따른다.
