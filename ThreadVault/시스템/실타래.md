# 실타래

파괴 시 사라지며 타입에 따라 서로 다른 [[실-버프]]를 얻을 수 있는 오브젝트이다.

## 타입
붉은색 / 푸른색 / 금빛 (타입 변동 가능성 있음.)

## 스폰
- 스테이지 시작 시 각 타입 실타래를 1개씩 생성한다.
- 지정된 스폰 후보 위치 중 하나에 생성한다.
- 이미 다른 실타래가 있는 위치에는 생성하지 않는다.
- 같은 타입의 실타래는 동시에 2개 이상 존재하지 않는다.
- 스테이지 1의 스폰 후보는 각 방 안에 2개씩 둔다 (총 12개). 방 배치는 [[스테이지]]를 따른다.
- 가장 최근에 플레이어가 실타래를 습득한 방에서는 실타래가 스폰되지 않는다. 새 실타래를 다른 방에서 습득하면 제한이 해당 방으로 이동한다.

## 재배치

- [[실-버프]]가 시간 만료 또는 반납으로 소모되면 남아 있는 실타래를 없애고 각 타입을 1개씩 새로 생성한다.
- 생성 위치는 스폰 후보 중 다시 랜덤하게 선택한다. 서로 같은 위치에 생성하지 않는다.
- 이 시점에는 보유 버프가 없으며, 이미 활성화된 [[좌표]]는 그대로 유지한다.
- [[우미아]]의 안내는 새 배치를 기준으로 한다.
