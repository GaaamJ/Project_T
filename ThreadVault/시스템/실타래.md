# 실타래

## 역할
파괴 시 사라지며 타입에 따라 서로 다른 [[실-버프]]를 얻을 수 있는 오브젝트이다.

## 동작
- 현재 씬 실행 시 붉은색 / 푸른색 / 금빛을 각 1개씩 생성한다.
- 플레이어의 공격을 받으면 해당 타입의 실 버프를 주고 사라진다.
- 버프가 반납되거나 만료되면 남은 실타래를 없애고 각 타입을 다시 생성한다.
- 다른 타입의 버프로 교체하면 이전 타입만 다시 생성한다.

## 규칙
- 지정된 후보 중 빈 위치를 랜덤으로 선택한다. 같은 위치에 중복 생성하지 않는다.
- 같은 타입의 실타래는 동시에 2개 이상 존재하지 않는다.
- 보유 중인 버프와 같은 타입의 실타래는 생성하지 않는다.
- 가장 최근에 플레이어가 실타래를 습득한 방에서는 실타래가 스폰되지 않는다. 새 실타래를 다른 방에서 습득하면 제한이 해당 방으로 이동한다.
- 수집한 위치는 다음 전체 재배치에서도 제외한다.
- 재배치 시 활성화된 [[좌표]]는 유지한다.
