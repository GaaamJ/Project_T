# 실타래

## 역할

파괴 시 사라지며 타입에 따라 서로 다른 [[실 버프]]를 얻을 수 있는 오브젝트이다.

종류를 만든 이유는 실(원인)에 따른 결과가 달라질 수 있다는 가능성을 열어 두고 싶어서다.

## 동작

### 생성과 획득

- 스테이지 시작(시작 구역 이탈) 시 붉은색 / 푸른색 / 금빛을 각 1개씩 생성한다. 대기 상태에서는 생성하지 않는다.
  - 색을 정할 때 운명의 붉은 실, 황금빛 양털로 짜인 실 같은 느낌을 생각했다.
- 플레이어의 공격을 받으면 해당 타입의 실 버프를 주고 사라진다.

### 재생성

- 버프가 반납되거나 만료되면 남은 실타래를 없애고 각 타입을 다시 생성한다.
- 다른 타입의 버프로 교체하면 이전 타입만 다시 생성한다.
  - 일단 실타래의 종류를 하나씩 유지해 보려고 정했다.

## 규칙

### 생성 위치

- 지정된 후보 중 빈 위치를 랜덤으로 선택한다. 같은 위치에 중복 생성하지 않는다.
  - 완전 랜덤이면 플레이어가 예측할 수 없고, 정해진 곳에서만 나오면 우미아 힌트의 가치가 사라진다고 생각해서 이 방식을 골랐다.
- 가장 최근에 플레이어가 실타래를 습득한 방에서는 실타래가 스폰되지 않는다. 새 실타래를 다른 방에서 습득하면 제한이 해당 방으로 이동한다.
  - 우미아 힌트의 가치를 높이려고 정했다.
- 수집한 위치는 다음 전체 재배치에서도 제외한다.
  - 이 제한도 우미아 힌트의 가치를 높이기 위한 것이다.

### 타입별 생성 제한

- 같은 타입의 실타래는 동시에 2개 이상 존재하지 않는다.
  - 종류별로 하나씩 두는 것이 자연스럽다고 생각했다.
- 보유 중인 버프와 같은 타입의 실타래는 생성하지 않는다.
  - 한 가지 원인을 선점했으니 더 이상 관련된 원인(실)이 나오지 않아야 한다고 생각했다. 다만 엄격한 원칙보다는 이 방식이 자연스럽게 느껴져서 선택했다.

### 다른 시스템과의 연동

- 재배치 시 활성화된 [[좌표]]는 유지한다.
