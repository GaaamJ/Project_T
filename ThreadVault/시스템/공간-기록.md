# 공간 기록

[[우미아]]가 방문한 공간을 기억한다. 플레이어가 방문한 공간만 [[우미아]]가 안내할 수 있다.

## 공간 구분

- 씬 내 영역을 Box Collider 2D (isTrigger)로 구분한다.
- 플레이어가 영역에 들어서는 순간 방문 처리한다.
- ID 형식: `{씬이름}_{SpaceTrigger 오브젝트 이름}` (예: `Stage1_RoomLeft1`)

## 저장

- json 파일로 영구 저장한다. 리트라이, 종료 후 재실행에도 유지된다.

## 첫 방문 대사

- 플레이어가 공간에 처음 방문하는 순간, [[우미아]]가 공간의 특징을 대사로 전달한다.
- 특징은 들어서는 즉시 시각적으로도 확인할 수 있어야 한다. (대사와 시각 일치)
- 재방문 시 반복하지 않는다.
- 호출 시점: SpaceTrigger 첫 방문 이벤트 → yarn spinner 노드 호출.

## 목표

- 첫 방문 시 공간 ID가 저장됨을 확인.
- 종료 후 재실행 시 저장된 ID가 유지됨을 확인.
- json 삭제 후 재방문 → 다시 기록됨을 확인.
- 재방문 시 우미아 대사가 반복되지 않음을 확인.

## 보류

- 각 공간의 구체적인 특징 텍스트 (방 테마 확정 후 작성).
- 첫 방문 대사 yarn spinner 노드 연결.
