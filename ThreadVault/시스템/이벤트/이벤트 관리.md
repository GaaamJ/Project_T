# 이벤트 관리

이벤트는 Yarn으로 진행 순서를 제어하는 이야기 단위다. 대사, 컷씬, 캐릭터 동작이 여기 해당한다.

이벤트 관리 시스템은 각 이벤트의 실행 조건과 완료 상태를 관리한다.

## 구성 요소

| 컴포넌트 | 역할 |
| --- | --- |
| EventDefinition | 이벤트 ID, Yarn Node, 반복 정책, 선행 이벤트 정의 |
| EventCatalog | 등록된 EventDefinition을 ID로 조회 |
| EventState | 완료된 이벤트 ID 목록 조회·기록 |
| EventRunner | 조건 검사, Yarn 실행, 완료 기록 |
| GameSessionManager | EventState를 씬 전환 간 보관 (DontDestroyOnLoad) |
| EncounterManager | Encounter 씬 시작 시 등록된 이벤트 실행 요청 |
| CutscenePresenter | `<<Cutscene>>` 커맨드 처리 |

## 실행 흐름

```text
씬·오브젝트가 이벤트 실행 요청
→ EventRunner.TryRun(eventId)
→ 실행 조건 확인 (반복 정책, 선행 이벤트, 중복 실행)
→ Yarn Node 시작
→ Yarn이 대사와 연출 진행
→ 정상 종료 시 EventState에 완료 ID 기록 및 저장
```

실행 거부, 중단, 오류는 완료로 기록하지 않는다.

## 실행 조건

### 반복 정책

| 정책 | 동작 |
| --- | --- |
| Once | 완료된 이벤트는 다시 실행하지 않는다 |

### 선행 이벤트

| 판정 방식 | 통과 조건 |
| --- | --- |
| All | 등록된 선행 이벤트를 모두 완료 |
| Any | 등록된 선행 이벤트 중 하나 이상 완료 |

선행 이벤트가 없으면 판정 방식과 관계없이 통과한다.

### 중복 실행 방지

한 번에 하나의 이벤트만 실행한다. 이벤트 실행 중 새 요청은 거부한다.

## 완료 상태

- 완료된 이벤트는 고유 ID로 구분한다.
- 완료 ID 목록은 게임 저장 파일에 포함된다.
- 같은 ID는 중복 저장하지 않는다.
- 영구적인 완료 상태는 이벤트 관리 시스템만 변경한다.

## 이벤트 추가

새 이벤트는 아래 세 단계로 추가한다.

1. Yarn Node를 작성한다.
2. EventDefinition 에셋을 생성한다.
3. 이벤트가 발생할 씬이나 오브젝트에 등록한다.

EventRunner, EncounterManager, SaveData에 이벤트별 코드를 추가하지 않는다.

## 확장

기존에 없는 기능이 필요하면 재사용 가능한 형태로 추가한다.

- 새로운 실행 조건 → EventDefinition.CanRun 확장
- 새로운 이벤트 발생 방식 → 새 Trigger 컴포넌트 추가
- 새로운 연출 → Yarn Command 추가 (시스템/Yarn 연동.md 참고)

## 규칙

- 모든 이벤트는 서로 겹치지 않는 고유 ID를 가진다.
- ID는 완료 상태의 저장 키이므로, 사용을 시작한 뒤 변경하지 않는다.
- Yarn 변수는 이벤트 내부의 임시 분기와 연출에만 사용한다.

## 설계 의도

이벤트마다 전용 관리자와 완료 여부를 따로 추가하면, 이벤트가 늘어날 때마다 기존 코드와 저장 구조를 수정해야 한다.

이를 피하기 위해 이벤트 내용은 Yarn에 두고, 실행 조건과 완료 상태는 공통 시스템에서 관리한다. 새 이벤트는 데이터 등록으로 추가하고, 새로운 기능이 필요할 때만 재사용 가능한 구현체를 추가한다.
