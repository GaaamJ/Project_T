# 스테이지 1 — 우미아 협력 대사

## 비전

- 플레이어에게 우미아가 도움이 되는 존재라는 것을 인식시킨다.
- 우미아가 실타래 위치를 알려주고, 플레이어가 그 정보를 바탕으로 이동함으로써 협력감을 만든다.

## 동작

실타래(Yarn)가 스폰되는 순간, 우미아가 자동으로 대사를 시작한다.

- **a케이스** — 스폰된 실타래의 방이 방문 기록에 있는 경우:
  그 방의 특징을 묘사하는 Node를 호출한다.

- **b케이스** — 스폰된 실타래의 방이 방문 기록에 없는 경우:
  "실타래가 느껴지지 않아요..." 같은 랜덤 Node를 호출한다.

- **c케이스** — save data가 없는 경우 (첫 시작):
  대사 없음.

Node 대사는 임시로 생성하며, 직접 수정 예정.

## 조건

**트리거**: 실타래 생성 직후 1회. 대사 실행 중이면 스킵.

**방 Id 판별**: `spawnPoint.transform.parent.name` + 현재 씬 이름 → `{SceneName}_{RoomId}` 형식으로 SaveManager.IsVisited() 조회.

**Node 명명 규칙**:
- a케이스: `{SceneName}_{RoomId}` (예: `SandBox_Room01`)
- b케이스: `UmiaNoSense_1`, `UmiaNoSense_2`, `UmiaNoSense_3` 중 랜덤

**스테이지 상태 연동**: 스테이지 상태(시작 전/진행/종료)에서 호출할 수 있는 public 메서드를 노출해 두되, 지금은 연결하지 않는다.

## 목표

save data 삭제 후 아래 루프를 3회 반복:

1. 게임 시작 → 실타래 스폰 → 대사 없음 (c케이스)
2. 맵 탐험 → 방 방문 → 해당 방에 실타래 스폰 → 그 방 묘사 Node 재생 (a케이스)
3. 미방문 방에 실타래 스폰 → 랜덤 "느껴지지 않아요" Node 재생 (b케이스)

## 보류

- 우미아 캐릭터성 대사 및 살아있다고 느끼게 할 기타 트리거
- 스테이지 상태(시작 전/진행/종료) 연동 실제 구현
- 대사 UI 레이아웃
