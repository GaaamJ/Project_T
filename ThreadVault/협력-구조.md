# 협력 구조

## 원칙

- 플레이어와 우미아는 서로에게 꼭 필요한 존재여야 한다.
- 개별 스테이지의 기믹과 우미아의 역할을 함께 설계한다.
- 협력 방식은 스테이지에 따라 달라져도, 캐릭터 설정상의 능력은 일관된 컨셉을 유지한다.
- 대사와 반응으로 우미아의 기여와 존재감을 전달한다.

## 게임 흐름

- 구출 전: 혼자서도 해결 가능. 함께할 때 우미아가 덜어 주던 부담을 혼자 재진행할 때 직접 감당한다.
- 구출 후: 반드시 둘이 있어야 해결할 수 있는 협력으로 확장한다.
- 전체 진행은 [[게임-흐름]]을 따른다.

## 스테이지 1 협력 구조

실타래 파괴 → 실 버프 획득 → 중앙 반납을 배우는 튜토리얼.

| 플레이어                 | 우미아                            |
| -------------------- | ------------------------------ |
| 방을 탐험하고 특징과 경로를 기억   | 방문한 방 중 현재 실타래가 있는 한 곳의 특징을 묘사 |
| 묘사를 해석하고 이동·확보·운반·반납 | 플레이어와 동행하며 현재 배치의 정보 제공        |

- 함께: 우미아의 묘사를 듣고 아는 방을 떠올려 출발한다.
- 혼자: 방과 길은 기억하지만, 현재 실타래 위치는 직접 확인한다.
- 실타래 재배치로 이전 위치 정보는 갱신해야 하지만, 방과 경로에 대한 기억은 계속 활용한다.
- 구체적인 배치는 [[스테이지]], 안내 규칙은 [[우미아]], 재배치는 [[실타래]]를 따른다.

## 검증할 점

- 안내를 듣고 이동 경로가 달라지는가.
- 방의 묘사를 명확하게 이해하고 활용하는가.
- 랜덤 안내가 실제로 헛걸음을 줄이는가.
- 혼자 탐색하거나 시간 만료 후 다시 찾는 과정이 지나치게 번거롭지 않은가.

## 현재 범위 밖

- 우미아의 자유 탐색·수집·반납 AI.
- 구출 이후의 구체적인 협력 기믹.
- 색별 포탈·역할·보스 패턴 등의 심화 기믹.
