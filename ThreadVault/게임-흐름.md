# 게임 흐름

시작 → 함께 스테이지 클리어 → 스토리적으로 중요한 사건 ( 페이크 게임 엔딩 ) → **맨 처음 스테이지부터** 혼자 전부 재진행 → 주인공이 남긴 힘으로 클리어 → 주인공 구출(서사적 성장) → 다시 함께 새로운 스테이지 진행 → 엔딩

## 기믹 스케일링

- 주인공 구출 전: 던전 스타일 — 혼자도 가능하나 탐색·반복 등의 부담을 직접 감당한다. 스테이지 1에서는 우미아의 위치 안내 없이 실타래를 직접 찾는다.
- 주인공 구출 후: 레이드 스타일 — 반드시 함께해야 클리어 가능

## 협력 설계

- 스테이지별 기믹과 우미아의 역할을 함께 설계한다. [[협력-구조]] 참고.
- 함께할 때 덜어 주던 부담을 혼자 재진행할 때 체감하게 한다.
