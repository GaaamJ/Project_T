# 게임 흐름

## 역할
방을 탐색하고 실을 가져와 좌표에 묶는 플레이 흐름.

## 동작
SandBox 씬 실행 → 시작 구역 대기 → 시작 구역 이탈 → 실타래 생성 → 방 탐색 → 실타래 공격 → 실 버프 획득 → 좌표에 묶기 → 실타래 재배치 → 탐색 반복 → 좌표 6개 활성화 → 스테이지 클리어.

- [[우미아]]가 플레이어와 동행한다.
- 방에 들어가면 [[공간-기록]]에 방문이 저장된다.
- 버프를 좌표에 묶거나 시간이 만료되면 실타래를 다시 배치한다.
- 활성화된 좌표는 재배치 후에도 유지한다.

## 규칙
좌표 6개 전체 활성화 시 클리어로 이어진다. 실패 조건은 미구현이며 이후 별도 이슈에서 연결한다.
