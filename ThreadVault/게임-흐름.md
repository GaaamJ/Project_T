# 게임 흐름

## 역할
방을 탐색하고 실을 가져와 좌표에 묶는 플레이 흐름.

## 동작
SandBox 씬 실행 → 실타래 생성 → 방 탐색 → 실타래 공격 → 실 버프 획득 → 좌표에 묶기 → 실타래 재배치 → 탐색 반복.

- [[우미아]]가 플레이어와 동행한다.
- 방에 들어가면 [[공간-기록]]에 방문이 저장된다.
- 버프를 좌표에 묶거나 시간이 만료되면 실타래를 다시 배치한다.
- 활성화된 좌표는 재배치 후에도 유지한다.

## 규칙
현재 좌표 활성화까지 연결되어 있다. 전체 좌표 활성화에 따른 클리어·문 개방과 실패·리트라이 흐름은 연결되어 있지 않다.
